# Surface: Piya-Skills landing (app/[lang]/page.tsx)

Mode: Persuade. Visitor: developer using an AI coding agent, Thai or international. Action: copy an install command; secondary: star the repo. Proof: the skill's real before/after output and its paired benchmark numbers. Bilingual TH/EN via /th and /en routes.

Constraints from the user: show a skill working first; must not look AI-overdone, must not look bigger than a one-skill collection, must feel Thai. Canon chosen on purpose; quality bar: reactbits.dev, vercel.com, skills.sh.

## Direction contract

THESIS: The category standard for a developer skill collection, executed at Vercel/skills.sh craft: a dark, precise page where the command and a live before/after demo carry everything. Refuses nothing of the canon; refuses decoration, hype copy and invented scale.

OWN-WORLD: Near-black ground #0a0a0a, raised panels #111111 with 1px #262626 borders, text #ededed, secondary #a1a1a1. Geist Sans and Geist Mono for Latin, Noto Sans Thai for Thai at matched x-height. Diff colours only inside demos: removed #f87171 struck, kept/added #4ade80. No gradients, no glow, no accent colour beyond white.

STORY: In one viewport the visitor sees what Piya-Skills is, a real skill rewriting real Thai text, and the one command that installs it. Scrolling: a skills table that grows row by row, paired test numbers stated as small samples, three install methods, a star ask.

FIRST VIEWPORT: Centered wordmark "Piya-Skills" (~72px desktop), one-line purpose, the install command box (TextType, copy button) directly under it, then the demo panel: audience tabs (Developer / General / Business) switching a diff view of the real skill output. Nav: wordmark, Skills, Install, TH|EN, GitHub star button with live count.

FORM: canon (category standard) chosen by the user; seed key c880ff70.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
